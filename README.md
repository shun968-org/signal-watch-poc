# signal-watch-poc

> **この PoC は終了しました(2026-10-17)。** 既製品と比べて優れている点が無いと判断し、サービスへの発展は見送りました。
> 結論・作ったもの・既製品との比較は [報告書](docs/report.md) にあります。リポジトリはアーカイブ済み(読み取り専用)です。

公開されている情報であっても、必要な情報を継続的に追いかけ、変更点を把握するには手間がかかる。特に、複数のWebサイトを定期的に巡回する必要がある場合、更新の見落としや確認作業の負担が課題になると考えた。    そこで、公開情報の更新を自動的に検出し、変更された箇所を分かりやすく提示する仕組みを試作する。まずは対象を限定して実用性を検証し、情報収集の効率化につながるサービスへ発展させられるかを探る。
