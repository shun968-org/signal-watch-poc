# ADR-0001: 取得したページは本文のテキストを抽出してから比較する

- ステータス: 採用
- 日付: 2026-01-01
- 関連: (書式の例示用。実在の決定ではない)

## コンテキスト

複数の Web サイトを定期的に取得し、前回からの変更点を利用者に提示する。
取得した HTML には、広告・アクセス数・日時表示・セッション ID など、内容の更新と無関係に毎回変わる部分が含まれる。
そのまま比較すると、実質的な更新が無くても「変更あり」と判定され、利用者が本当の更新を見落とす。

### 検討した選択肢

| 案 | 却下理由 |
|---|---|
| HTML 全体をそのまま比較する | 無関係な部分の変化で誤検知が多発し、通知が信用されなくなる |
| 画面のスクリーンショットを画像で比較する | 差分の箇所を文章として提示できない。描画のたびの微妙な揺れでも差分が出る |

## 決定

**取得したページは、対象ごとに指定した領域から本文のテキストを抽出し、そのテキスト同士を行単位で比較する。**

判断の根拠:

1. **誤検知を減らせる。** 比較の対象を、利用者が追いかけたい領域に限定できる。
2. **変更点を文章として示せる。** 追加・削除された行をそのまま提示できる。

## 結果

- 対象ごとに抽出する領域(CSS セレクタなど)の定義が必要になり、登録の手間が増える。
- サイトの構造が変わると抽出に失敗する。抽出結果が空になったときは、変更ではなく取得の失敗として扱う。
- 表や画像の変化は検出できない。必要になったら別 ADR で扱う。
